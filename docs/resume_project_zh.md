# 简历项目描述

以下版本均基于项目中已经完成并验证的工作，不夸大排行榜成绩或模型效果。

## 推荐项目名称

**Titanic 乘客生存预测｜数据分析与机器学习**

## 数据分析岗位版本

- 使用 pandas 完成 891 条乘客数据的质量检查、缺失值分析与探索性分析，
  识别性别、舱位等级和家庭结构与生存率之间的主要关联；
- 构造称谓、家庭规模、同行票号、舱位甲板等特征，并通过消融实验验证特征
  有效性，避免仅凭经验堆叠变量；
- 使用分组置换重要性解释模型结果，形成可复现的分析报告、可视化图表和
  Kaggle 提交记录，最终得分 0.78229。

## 机器学习岗位版本

- 将原始探索脚本重构为 scikit-learn Pipeline，统一缺失值处理、类别编码、
  特征工程和模型训练，修复使用目标变量填补年龄造成的数据泄漏；
- 比较逻辑回归、随机森林、Extra Trees 和梯度提升，采用 5 折 × 3 次重复
  验证及家庭—票号分组验证评估泛化性能；
- 设计“一标准误差候选集 + 分组稳健性”选模规则，Extra Trees 分组准确率
  达 0.8238，Kaggle 得分由 0.77751 提升至 0.78229；
- 添加单元测试、GitHub Actions、提交文件版本和 SHA-256 校验，确保结果
  可复现且可审计。

## 一页简历精简版

- 重构 Titanic 二分类项目，使用无泄漏 Pipeline、重复/分组交叉验证及特征
  消融比较 4 类模型；最终 Extra Trees 分组 CV 准确率 0.8238、Kaggle
  0.78229，并完成模型解释、自动测试与可复现文档。

## 技术栈

Python、pandas、NumPy、scikit-learn、Matplotlib、Git、GitHub Actions、
交叉验证、集成学习、特征工程、模型解释

## 面试中不要这样表述

- 不说“模型准确率达到 83%”而不说明这是交叉验证；
- 不把 Kaggle 0.78229 表述成独立测试集上的 83%；
- 不声称性别或舱位“导致”生存，只表述为数据中的关联和预测信息；
- 不声称 Extra Trees 显著优于所有模型，应说明普通验证近似打平，但分组
  验证更稳定。
